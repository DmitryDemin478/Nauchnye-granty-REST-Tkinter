# Научные гранты — Tkinter + REST API

Проект разделён на две части:
- `backend.py` — REST-сервис на FastAPI. Он выполняет операции и работает с базой SQLite.
- `main.py` — графическое приложение Tkinter. Оно отправляет HTTP-запросы REST-сервису и показывает результат пользователю.

## Установка

Нужен Python 3.10 или новее.

Откройте командную строку в папке проекта и выполните:

```cmd
py -m pip install -r requirements.txt
```

## Запуск

**1. Запустите REST-сервис.** В первом окне командной строки:

```cmd
py -m uvicorn backend:app --reload
```

Не закрывайте это окно. Сообщение `Uvicorn running on http://127.0.0.1:8000` означает, что сервер запущен.

**2. Запустите интерфейс Tkinter.** Откройте второе окно командной строки в той же папке:

```cmd
py main.py
```

Теперь программа Tkinter будет получать и отправлять данные через REST-сервис.

Документация API доступна по адресу http://127.0.0.1:8000/docs.

## Возможности

Гость может просматривать и искать гранты. Исследователь может зарегистрироваться, войти, редактировать профиль, подавать заявки на активные гранты и просматривать их статусы. Администратор может добавлять и изменять гранты, просматривать заявки и исследователей, одобрять и отклонять заявки.

## Хранение данных

База `nauchnye_granty.db` создаётся автоматически рядом с `backend.py`. Данные сохраняются между запусками. При первом запуске создаются три демонстрационных гранта.

## Важно

Сначала всегда запускайте REST-сервис, затем Tkinter. Если сервер не запущен, графическая программа покажет сообщение с инструкцией.

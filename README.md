# Научные гранты — ЛР № 3

**Автор:** Дёмин Д. В.  
**Группа:** СН-31

## Назначение

REST-сервис предназначен для просмотра и поиска научных грантов, регистрации исследователей, подачи заявок и их рассмотрения администратором. Реализация продолжает проект ЛР № 2 и использует Python, FastAPI и Pydantic.

## Структура проекта

- `backend.py` — HTTP-маршруты FastAPI и обработка ошибок запросов.
- `service.py` — интерфейс сервиса `GrantService`.
- `service_impl.py` — реализация `GrantServiceImpl`, временное хранилище и бизнес-правила.
- `models.py` — внутренние модели гранта, исследователя и заявки.
- `schemas.py` — DTO входных данных и их проверка.
- `mapper.py` — преобразование внутренних моделей в ответы API.
- `tests/` — модульные и HTTP-проверки.
- `main.py` — графический интерфейс Tkinter, использующий REST API.
- `API_CONTRACT.md` — описание доступных операций API.
- `requirements.txt` — зависимости проекта.

## Установка

Откройте PowerShell в каталоге проекта и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

## Запуск

В первом окне PowerShell запустите REST-сервис:

```powershell
py -m uvicorn backend:app --reload
```

Документация Swagger UI: http://127.0.0.1:8000/docs

Для запуска графического интерфейса откройте второе окно PowerShell и выполните:

```powershell
py main.py
```

## Учётная запись администратора

- Электронная почта: `admin@grant.ru`
- Пароль: `admin123`

Обычная регистрация создаёт учётную запись с ролью «Исследователь». Роль администратора не передаётся при обычной регистрации.

## Проверка

Запуск модульных и HTTP-тестов из каталога проекта:

```powershell
py -m unittest discover -s tests -v
```

Тесты проверяют бизнес-правила БП-01—БП-08, сохранение старых GET-операций, создание заявки, заголовок `Location`, получение созданной заявки, ошибки валидации и конфликт повторной подачи.

## Временное хранение

Гранты, исследователи и заявки хранятся в памяти экземпляра `GrantServiceImpl`. После перезапуска сервера добавленные исследователи, заявки и гранты исчезают. Три исходных демонстрационных гранта и отдельная учётная запись администратора создаются заново. Постоянное хранение данных в этой лабораторной работе не реализуется.

# Научные гранты — лабораторная работа № 3

**Автор:** Дёмин Д. В.  
**Группа:** СН-31

## Назначение

В лабораторной работе № 3 REST API переработан с разделением на контроллер, интерфейс сервиса и его реализацию. Клиентское приложение Tkinter обращается к API по HTTP и получает данные в формате JSON.

## Структура проекта

- `main.py` — графический клиент на Tkinter.
- `backend.py` — контроллер REST API: принимает HTTP-запросы, вызывает сервис и возвращает ответы.
- `service.py` — интерфейс сервиса `GrantService`.
- `service_impl.py` — реализация `GrantServiceImpl` и проверки правил предметной области.
- `models.py` — модели гранта, исследователя и заявки.
- `schemas.py` — DTO и проверка входных данных с помощью Pydantic.
- `mapper.py` — преобразование моделей в объекты ответа API.
- `tests/` — модульные и HTTP-тесты.
- `API_CONTRACT.md` — описание REST API.

## Реализованные операции API

- `GET /api/health` — проверка доступности сервиса.
- `POST /api/auth/login` — вход пользователя.
- `POST /api/researchers` — регистрация исследователя.
- `PUT /api/researchers/{user_id}/profile` — изменение профиля.
- `GET /api/researchers` — получение списка исследователей.
- `GET /api/grants` — получение и поиск грантов.
- `GET /api/grants/{grant_id}` — получение одного гранта.
- `POST /api/grants` — добавление гранта.
- `PUT /api/grants/{grant_id}` — изменение гранта.
- `POST /api/applications` — подача заявки.
- `GET /api/applications` — получение списка заявок; параметр `researcher_id` позволяет получить заявки одного исследователя.
- `GET /api/applications/{application_id}` — получение одной заявки.
- `PUT /api/applications/{application_id}/status` — изменение статуса заявки.

Документация Swagger после запуска доступна по адресу `http://127.0.0.1:8000/docs`.

## Проверки предметной области

В реализации сервиса предусмотрены проверки БП-01–БП-08: обязательные сведения при регистрации, положительная сумма гранта, корректность дат, активность гранта, соответствие специальности направлению гранта, отсутствие повторной заявки, начальный и итоговый статусы заявки, назначение роли исследователя при регистрации.

## Хранение данных

В текущей учебной реализации данные хранятся в памяти экземпляра `GrantServiceImpl`. При перезапуске сервера демонстрационные гранты создаются заново, а зарегистрированные пользователи и заявки сбрасываются. Постоянное хранение в базе данных в этой версии не реализовано.

## Установка и запуск

Рекомендуется использовать Python 3.13 или новее.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py -m uvicorn backend:app --reload
```

После запуска доступны:

- API: `http://127.0.0.1:8000`
- Swagger: `http://127.0.0.1:8000/docs`

Для запуска графического клиента в отдельном окне терминала:

```powershell
py main.py
```

Демонстрационная учётная запись администратора:

- Электронная почта: `admin@grant.ru`
- Пароль: `admin123`

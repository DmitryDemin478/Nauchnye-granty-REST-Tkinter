# Контракт REST API — «Научные гранты»

Базовый адрес API: `http://127.0.0.1:8000`. Формат данных: JSON, кодировка UTF-8.

## 1. Получение списка грантов

- **Роль и требование ЛР № 1:** гость, исследователь; ФТ-01/ФТ-02.
- **Назначение:** получить демонстрационный список грантов. При передаче параметра `search` выполнить поиск по названию или направлению.
- **Метод и путь:** `GET /api/grants`.
- **Входные данные:** необязательный query-параметр `search` типа string. Если параметр отсутствует, возвращаются все записи. Поиск не зависит от регистра.
- **Успешный ответ:** `200 OK`.

Пример полного ответа без параметра `search`:

    "name": "Исследование биоразнообразия Астраханской области",

    "direction": "Биология",
    "amount": 450000.0,

    "date_end": "2027-08-31",
    "active": true

  {
    "id": 2,

- **Другие ответы:** `200 OK` и `[]`, если совпадений нет. Для этого метода ошибки валидации параметра поиска не предусмотрены, поскольку параметр является строковым.
- **Готовность:** реализована.

## 2. Получение сведений об отдельном гранте

- **Роль и требование ЛР № 1:** гость; ФТ-01.
- **Назначение:** получить полную информацию о гранте по его идентификатору.
- **Метод и путь:** `GET /api/grants/{grant_id}`.
- **Входные данные:** обязательный параметр пути `grant_id` — строковое представление целого числа. Строковый тип используется для самостоятельной обработки нечислового значения и возврата статуса `400`.
- **Успешный ответ:** `200 OK`.

Пример полного ответа для `GET /api/grants/1`:

```json
{
  "id": 1,
  "name": "Исследование биоразнообразия Астраханской области",
  "description": "Изучение состояния и сохранения биоразнообразия региона.",
  "direction": "Биология",
  "amount": 450000.0,
  "date_start": "2026-09-01",
  "date_end": "2027-08-31",
  "active": true
}
```

- **Другие ответы:**
  - `400 Bad Request` — идентификатор не является целым числом. Пример тела: `{"detail":"ID должен быть целым числом."}`.
  - `404 Not Found` — идентификатор является целым числом, но грант с таким ID отсутствует. Пример тела: `{"detail":"Грант не найден."}`.
- **Готовность:** реализована.

## 3. Подача заявки на участие в гранте

- **Роль и требование ЛР № 1:** исследователь; ФТ-04/ФТ-05.
- **Назначение:** передать заявку исследователя на участие в выбранном гранте.
- **Метод и путь:** `POST /api/applications`.
- **Входные данные:** JSON-объект с идентификаторами исследователя и гранта.

Пример входного JSON:

```json
{
  "researcher_id": 2,
  "grant_id": 1
}
```

- **Предполагаемый успешный ответ:** `201 Created`.

Проектный пример тела ответа:

```json
{
  "id": 7,
  "status": "На рассмотрении"
}
```

- **Предполагаемые отказы:**
  - `400 Bad Request` — выбранный грант неактивен либо специальность исследователя не соответствует направлению гранта.
  - `404 Not Found` — исследователь или грант с указанным идентификатором не найден.
  - `409 Conflict` — исследователь уже подавал заявку на этот грант.
- **Готовность:** запланирована, в версии ЛР № 2 не реализована. Указанные для POST статус и тела ответов являются проектом контракта, а не результатом выполненного запроса.

# Контракт REST API — «Научные гранты»

Базовый адрес: `http://127.0.0.1:8000`. Формат обмена: JSON, кодировка UTF-8. Интерактивная документация доступна по адресу `/docs`.

| Метод | Путь | Назначение | Успешный ответ |
|---|---|---|---|
| GET | `/api/health` | Проверка доступности API | 200 |
| POST | `/api/auth/login` | Вход по электронной почте и паролю | 200 |
| POST | `/api/researchers` | Регистрация исследователя | 201 |
| PUT | `/api/researchers/{user_id}/profile` | Изменение профиля | 200 |
| GET | `/api/researchers` | Список исследователей | 200 |
| GET | `/api/grants` | Список грантов и поиск по `search` | 200 |
| GET | `/api/grants/{grant_id}` | Сведения о гранте | 200 |
| POST | `/api/grants` | Добавление гранта | 201 |
| PUT | `/api/grants/{grant_id}` | Изменение гранта | 200 |
| POST | `/api/applications` | Подача заявки | 201 |
| GET | `/api/applications` | Список заявок; необязательный `researcher_id` | 200 |
| GET | `/api/applications/{application_id}` | Сведения о заявке | 200 |
| PUT | `/api/applications/{application_id}/status?status=Одобрена` | Изменение статуса на «Одобрена» или «Отклонена» | 200 |

## Основные форматы запросов

Регистрация исследователя (`POST /api/researchers`):

```json
{
  "fio": "Иванов Иван Иванович",
  "specialty": "Биология",
  "degree": "Кандидат наук",
  "achievements": "Публикации",
  "email": "ivan@example.ru",
  "password": "1234"
}
```

Добавление или изменение гранта (`POST /api/grants`, `PUT /api/grants/{grant_id}`):

```json
{
  "name": "Название гранта",
  "description": "Описание исследования",
  "direction": "Биология",
  "amount": 100000,
  "date_start": "2026-01-01",
  "date_end": "2026-12-31",
  "active": true
}
```

Подача заявки (`POST /api/applications`):

```json
{
  "researcher_id": 2,
  "grant_id": 1
}
```

## Коды ошибок

- `400 Bad Request` — некорректные входные данные, неактивный грант или несовпадение специальности и направления.
- `401 Unauthorized` — неверные данные для входа.
- `404 Not Found` — объект с указанным идентификатором не найден.
- `409 Conflict` — повторная регистрация с тем же адресом электронной почты или повторная заявка на тот же грант.

## Правила предметной области

Сервис проверяет обязательные поля исследователя, положительную сумму гранта, порядок дат, активность гранта при подаче заявки, соответствие специальности исследователя направлению гранта и отсутствие повторных заявок. Новая заявка получает статус «На рассмотрении». Администратор может изменить его на «Одобрена» или «Отклонена».
